JAK URUCHOMIĆ NA TELEFONIE
Najprościej wrzuć folder na dowolny hosting statyczny HTTPS, np. GitHub Pages, Netlify lub Cloudflare Pages.
Potem otwórz adres w Chrome na Androidzie i wybierz „Dodaj do ekranu głównego” / „Zainstaluj aplikację”.

DO SZYBKIEGO TESTU NA KOMPUTERZE
W tym folderze uruchom:
python -m http.server 8000
i wejdź na:
http://localhost:8000

UWAGA
Dane są przechowywane lokalnie w przeglądarce (localStorage).
Regularnie używaj eksportu JSON jako kopii zapasowej.
